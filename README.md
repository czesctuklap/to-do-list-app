# To-Do List App

A simple iOS To-Do List app in Swift for managing tasks. The app allows user to create and delete tasks.

### Features
- **Add Tasks**: Users can add tasks to the list by typing into the input box and clicking the `+` button.
- **Delete Tasks**: Users can delete tasks by clicking the trash icon or by shaking the phone - which deletes all tasks.
